This site sets no cookies, counts no visits and loads nothing from other servers: typeface, images and stylesheet
come from the site itself.

The site is hosted on GitHub Pages, a service of GitHub, Inc. Like every web server, GitHub logs the IP address of
visitors to run and protect the service. What GitHub does with it is in
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Links lead to GitHub, where the source code and the downloads are. GitHub's privacy statement applies there.
