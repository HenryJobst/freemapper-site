For each German state there is a sprint map and a forest map, each of an area from which freemapper can derive a lot.
Most images show the **check print**: the map with every candidate, true to position, as one takes it into the terrain
to check. It shows what freemapper derives and so looks fuller than a finished map. Viktoriapark already shows the
**training map**, which one prints and runs on as it is; the other examples follow.

Click an image to see it large. The PDFs and the whole projects with OOM and OCAD files are on GitHub.
